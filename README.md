Life Long Learn - Your Personal AI Study Assistant
=================================================

Overview
--------
Life Long Learn is a personal AI study assistant. It analyzes your academic
records and learning style to generate personalized study plans, custom
quizzes, and learning strategies tailored to you.

Tech Stack
----------
- Backend: Python, Flask, Flask-SQLAlchemy, SQLite
- AI: Ollama (local models)
- Frontend: HTML, Bootstrap, Font Awesome

Quick Start
-----------
1. Install dependencies:
   python -m pip install -r backend/requirements.txt
2. Run the app:
   python backend/app/main.py
3. Open http://localhost:5000 in your browser.

Demo
----
Open demo.html in any browser for a standalone, no-backend preview.

Features
--------
- Personalized study plans based on learning style
- AI-generated custom quizzes
- Learning style assessment questionnaire
- Multi-user accounts with private data
- Academic record tracking
